# Serve

服务器自研服务源码及第三方软件目录约定。

```text
service/
  cuo/              CuO 后端、前端、测试与运维源码
software/           第三方软件占位，仅含说明和 .gitkeep
```

详见 [CuO 使用说明](service/cuo/README.md) 和 [第三方软件占位说明](software/README.md)。

## 源码范围

本副本取自当前服务器实际部署代码。包含自研源码、前端、资源、测试、数据库迁移和部署模板。
软件运行环境及其安装包需在目标机器重新安装；真实配置和数据由部署环境提供。
`var` 中仅提交目录占位，不包含模型密钥、聊天记录、个人文件、数据库、日志或备份。
旧本地工作内容保留在原位置，并通过 `.gitignore` 排除。
